# Yuri Ante · Koi Portfolio

An interactive pixel-art portfolio pond for Yuri Ante. The pond includes seven project koi, a field-notebook project journal, a dockside About board, a drifting Contact boat, organic water lighting, cloud shadows, wildlife, cursor ripples, and click-driven fish reactions.

## Run locally

Live site: https://pok0yo.github.io/koi-portfolio/

GitHub Pages publishes the root of `main`. Push a commit to `main` to update the site. `index.html` opens `koi-portfolio.html`, which remains the editable source.

Extract the package and start a local HTTP server from its root directory. For example:

```powershell
py -m http.server 8765
```

Then open `http://127.0.0.1:8765/koi-portfolio.html`. A local server is recommended because browser security rules can restrict local asset downloads when the HTML file is opened directly. The page uses the Pixelify Sans web font from Google Fonts; an Internet connection is needed for the intended typography unless the font is already cached.

## Editing content and settings

Project names and project metadata are defined near `PROJECTS` and `PROJECT_DETAILS` in `koi-portfolio.html`. Personal About and Contact content is generated by the `renderPersonalContent` functions. Major visual and movement settings are grouped in `CONFIG`, `WATER`, `CLOUD`, `ECO`, `REACTION`, and `OBJECT_SCALE`.

Five practice entries use supplied screenshots with full-image links that open in a new tab. Flutter Learning App and Sales Automations retain labeled placeholders. Each entry links to the personal GitHub profile, not a project repository; unavailable demo and repository links remain omitted. Practice entries cite official Odin Project assignments as learning context, not evidence of implemented features.

The public résumé PDF was exported with Microsoft Word from an unsaved copy of Yuri_Ante_Resume.docx with its contact line replaced. It retains the professional email and LinkedIn, while omitting the street address and phone number. The original DOCX and private PDF remain unchanged locally. The private PDF, temporary files, diagnostics, and old packages are excluded from Git. Update About and the public PDF together when the résumé changes, and verify private details are absent before publishing.

The ZIP under deliverables is an older snapshot and has not been refreshed with these content or asset updates.

## Interaction and accessibility

Click a project koi to open its journal entry. Clicking exposed water creates a ripple; nearby koi scatter and regroup while nearby small fish briefly scatter and return to their own schools. The Projects journal, About dock, and Contact boat are keyboard-accessible. Escape and visible close/back controls close information surfaces and restore focus to the originating control. The Still water pad freezes animation and click reactions, and the system `prefers-reduced-motion` setting is respected on load.

## Runtime notes

The portfolio uses browser-native HTML, CSS, canvas, and vanilla JavaScript. It has no build step or framework. Pixelify Sans is an external Google Fonts dependency; the rest of the packaged runtime assets are local. No unavailable links or invented project outcomes are included.
